# Reports

Notebook-generated evaluation artifacts live here:

- `labor_filter_summary.json`: summary from the Gemini corpus filtering notebook.
- `ragas_questions.json` / `ragas_questions.md`: frozen benchmark questions generated by RAGAS TestsetGenerator.
- `retrieval_evaluation.json` / `retrieval_evaluation.md`: retrieval-only comparison across BM25, vector, hybrid, Hybrid RRF, and Hybrid RRF + MMR. Notebook 02 ranks candidates but does not select the final method.
- `rag_answers.json`: generated or cached answers for the final retrieval candidates from notebook 03.
- `ragas_evaluation.json` / `ragas_evaluation.md`: RAGAS answer metrics from `ragas.evaluate()` plus the final method selection. Cached answer/metric usage is marked explicitly.
- `figures/`: notebook-ready comparison charts.

Generate and analyze these files from `notebooks/02_retrieval_experiments.ipynb` and `notebooks/03_ragas_evaluation.ipynb`. Deploy-facing Python code does not generate benchmark reports.

Run with `GEMINI_API_KEY` or `GEMINI_API_KEYS` configured to regenerate the RAGAS benchmark questions and answer metrics with Gemini. Keys must stay in `.env` or the shell environment and must not be committed.
